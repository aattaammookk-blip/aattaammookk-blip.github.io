# 正史中的人相食 · 专题历史数据库

二十四史（含《清史稿》）中「人相食」相关记载的搜集、整理与考辨。

**双击 `index.html` 即可使用。** 不联网、不安装、不需服务器。

---

## 这是什么

一套以事件为锚点的专题数据库，把正史里散落的「人相食」记载整理成可检索、可比较、可溯源的结构化材料，严格区分两类性质不同的东西：

| 类别 | 数量 | 说明 |
|---|---|---|
| 正式事件 | **201** | 判定为实际发生的人相食事件，构成名录、时间轴、地图的主体 |
| 关联史料 | **311** | 201 条事件所辖的记载条数 |
| 排除材料 | **210** | 检索命中而不符合收录标准：同形异义、修辞、典故、占辞讹言、泛述、族俗 |

两类合计 **521 条记载**，即全库「人相食」相关记载的总数。事件数不等于史料数，也不等于检索命中数。

> 2026-11-02 复核：19 条原列「非事件材料」的记载已逐条改判归位，该类目取消；逐条理由见 `docs/08_非事件材料复核.md`。

## 功能

- **事件名录**：固定双栏。左侧列表（年代、朝代、地点、类型、概述、史料数、判定），右侧详情（基本信息／概述／全部史料原文／进阶信息），各自滚动，切换事件不跳动。
- **史料原文**：按底本偏移还原为**完整自然段**（繁体，未删节），命中句黄底高亮，缺字红框标出；可一键显示机器转换的简体对照。
- **整篇原文**：每条史料可点「查看整篇原文」，弹出该篇全文（363 篇，繁体，未删节），自动滚到命中处并标黄。原文按史书拆成 24 个文件，点开才加载，不影响首屏。
- **时间轴**：朝代分区＋年代刻度＋类型着色节点，支持 1×–8× 缩放；区间事件画长条、推定年份画空心虚线圆。
- **历史地图**：三段式（控制区／地图主体／右侧详情）。地形晕渲 + 海岸线 + 湖泊 + 分级水系，墨卡托投影，水陆边界与矢量同源（无错缝）；缩放 1×–6×、平移有边界；点位按 12 px 聚合，可切换「事件点位／密度分布」，按朝代、年份、类型、定位精度筛选；点地点看事件、点事件进详情。**不画国界与历史疆域**。
- **地点与人物**：157 处地点按区域分组（含今地与定位精度），169 位人物按事件索引。
- **搜索与筛选**：关键词覆盖编号、年代、朝代、地点、人物、类型、史书、篇名、原文、概述；**输入后按回车或点「搜索」才开始检索**，不会边打字边跳转。支持朝代／类型／地点／年份区间／精度组合筛选与四种排序。

## 运行方式

直接双击 `index.html`。全部资源以相对路径的普通 `<script src>` / `<link>` 引入，不使用 fetch、ES module、CDN 或任何在线服务，因此 `file://` 协议下功能完整（整篇原文的动态载入亦已在 `file://` 下验证）。

**关于体积**：`index.html` 只有 7 KB，是页面骨架；数据在 `assets/data.js`（1.37 MB），整篇原文在 `assets/texts/`（11.1 MB）。首屏只加载 1.5 MB，整篇原文点开才载入对应那一部（最大 1.3 MB）。若不需要整篇原文，删掉 `assets/texts/` 即可，史料卡中的命中段落不受影响（按钮会提示原文未随包提供）。

若浏览器对本地文件有限制，用任意静态服务器打开亦可：

```bash
python -m http.server 8000
# 浏览器访问 http://127.0.0.1:8000/
```

浏览器要求：Chrome / Edge / Safari / Firefox 近三年版本。不支持 IE。

## 数据来源与限制

- 史文取自电子转录的二十四史全文库，经关键词检索、机器预判、人工复核后抽取要素。
- **底本不是校勘定本**，未与纸本逐字校对，不得标注为「中华书局点校本某卷某页」。正式引用须核对纸本或权威影印本。
- 繁简混排（多数繁体，少数篇目简体），未统一转换；部分篇目含私用区缺字，页面以红色 □ 标出。
- 详细口径、字段定义、判定标准、已知问题，见 `docs/` 与页面内「资料说明」。

## 重建数据

```bash
python build/build_data.py      # 从原 HTML 抽取并生成 assets/data.js（含 19 条复核改判）
python build/build_texts.py     # 导出 363 篇整篇原文，按史书拆成 assets/texts/bNN.js
python build/build_places.py    # 生成地点定位表
python build/build_basemap.py   # 生成地形晕渲与矢量底图（首次运行需联网下载约 130 MB 素材）
```

四个脚本只读原库，不改动原始文件。

# 五、页面结构与交互说明

## 1. 文件结构

```
人相食主题总库/
├── index.html              入口（约 8 KB，纯结构，不含数据）
├── assets/
│   ├── app.css             全部样式（约 37 KB）
│   ├── app.js              全部交互逻辑（约 88 KB）
│   ├── data.js             数据层（1.76 MB，window.DB）
│   ├── places.js           地点定位表（window.PLACE_GEO／EVENT_PLACE／EVENT_PLACES）
│   ├── basemap.js          矢量底图：海岸线／湖泊／水系（588 KB）
│   ├── terrain.jpg         地形晕渲（1.2 MB，2400×1729）
│   ├── about.js            资料说明正文
│   └── texts/              479 篇整篇原文，按史书分 25 个文件（14.5 MB，按需加载）
├── docs/                   六份说明文档
└── build/                  构建脚本（可重跑，不影响运行）
```

双击 `index.html` 即可使用。全部脚本以普通 `<script src>` 引入，**不使用 fetch、ES module、CDN 或任何在线服务**，因此 `file://` 协议下功能完整；断网可用。

## 2. 导航与模块

| 模块 | 路由 | 说明 |
|---|---|---|
| 总览 | `#/overview` | 三张统计卡、四个入口、朝代分布（条形）、事件类型（条形）、史书分布（**饼图**，可点选查看单部明细）（不设页首大标题） |
| 事件名录 | `#/events` | 固定双栏：左列表、右详情 |
| 时间轴 | `#/timeline` | 朝代分区＋年代刻度＋节点＋列表，支持 1×/2×/4×/8× 缩放；只留筛选下拉，不设搜索框 |
| 历史地图 | `#/map` | 三段式：控制区／地图主体／右侧详情；地形晕渲 + 海岸线湖泊水系 + 点位或密度 |
| 地点索引 | `#/places` | 地点按区域分组，顶部只有一个搜索框（不显示事件筛选条） |
| 人物索引 | `#/persons` | 人物按事件数排列、可搜索、点开看其事件表 |
| 排除材料 | `#/excluded` | 左侧类别目录（13 族 21 类）、右侧材料卡；入口在**顶栏右侧**，与「资料说明」「简体对照」并列，不占导航条 |
| 资料说明 | `#/about` | 九节学术说明；入口同上 |

排除材料有**独立入口**（顶栏右侧按钮），不藏在任何折叠区里；顶栏原「260 正式事件／397 关联史料／323 排除材料」三个数字已移除（总览页的三张统计卡保留）。

## 3. 事件名录的双栏结构

```
┌──────────────┬─────────────────────────────┐
│ 筛选条（跨两栏）                            │
├──────────────┼─────────────────────────────┤
│ 列表（独立滚动）│ 详情（独立滚动）              │
│ 392 px       │ 自适应                        │
└──────────────┴─────────────────────────────┘
```

- 两栏高度锁定为视口高度减去页头、导航与筛选条，**同时可见，各自滚动**。
- 点击左侧条目只做三件事：更新选中样式、重绘右侧、写入 URL。**列表 DOM 不重建**，所以滚动位置不会跳动，筛选条件也不会丢失。
- 未选中时右侧显示引导文案，不留空白。
- 详情头部固定「上一事件／下一事件／回到顶部」；移动端另有「返回列表」。
- 移动端（≤820 px）改为列表页与详情页切换，选中后详情占满，带明确返回按钮。

## 4. 详情的三段结构

1. **基本信息**：年代原文、朝代、公元年、年份精度、地点、事件类型、涉及人物（宽屏四列，窄屏两列）。
2. **事件概述**：白话提要。
3. **相关史料**：每条一张卡——史书·篇名·篇章类别；记载年代／地点／人物；**完整繁体段落**（命中句黄底高亮，缺字红框）；可选的简体对照；「查看整篇原文」。

> 2026-11-03 起，正文页不再呈现「收录判定」、概述下方的「非史料原文」提示、「原始序号 rank」、事件级「进阶信息」板块与史料卡内的「进阶信息」折叠。这些字段**仍完整保存在 `data.js`**（`verdict`／`rank`／`audit`／`note`／`place_fix`／`same_source` 等），只是不在 HTML 中展开，必要时可直接从数据层取用。

## 5. 筛选与搜索

筛选条在名录、时间轴、地图三页复用同一份事件状态（地点索引另有独立的 `placeQ`，人物索引另有 `personQ`）：

```js
{ q, dyn, type, yFrom, yTo, prec, place, book, sort }
```

- **搜索**：事件编号、年代、朝代、地点、人物、类型、史书、篇名、史料原文、概述，全部拼成一个检索串，子串匹配。
  **输入时不检索**：在输入框键入文字不会触发筛选，须按回车或点击「搜索」按钮才开始检索；点输入框右侧「×」或「清空筛选」立即清除。这样避免边打字边跳转、每敲一个字列表就重排。排除材料与人物索引的搜索框同样处理。
- **朝代**：按历史顺序，显示「朝代（条数）」。
- **类型**：五分类，沿用现有字段。
- **地点**：246 个基名，等值匹配（不再用子串，避免「河南」误中「河南府路」）；异名同地者归一（「江、淮间」并入「江、淮」）。并列数地的事件按单地拆分，选中任一子地点都能检出该事件（如选「沂州」得 EV0183）。
- **年份**：起止输入框，区间事件按 `[起, 止]` 与查询窗口求交。
- **精度**：单年／区间／推定。
- **史书**：按史书筛选，选项后附该书记载条数（如「明史（34）」）；命中条件为该事件至少有一条史料出自所选史书。可与朝代、类型、地点等条件叠加。
- **排序**：时间升序（默认）／时间降序／关联史料数／朝代顺序。
- **当前生效条件**以 chip 形式列在筛选条下方，每个可单独移除；另有「清空筛选」按钮。
- 结果计数固定显示「当前 N / 260 条」。

筛选状态在名录、时间轴、地图三页之间**共享**：在地图选「明」，切到名录仍是 31 条。地点索引不参与事件筛选，始终列出全部 246 处；在其中点地点会先弹出预览窗，窗内「跳转至事件名录（按此地点筛选）」才会把该地点写入名录的条件。

排除材料页使用**独立的搜索词**（`exQ`），不与事件筛选串味；否则在排除卷里搜「奏疏」，切到地图会只剩零个点。

## 6. 交互状态

| 状态 | 表现 |
|---|---|
| 默认 | 白底、细边框、暖白页底 |
| 悬停 | 边框转主色、底色转浅红、条目轻微上浮 |
| 选中 | 左侧条目浅红底＋左侧 3 px 主色竖线；时间轴节点加深外圈；地图点位不变形但侧栏联动 |
| 展开 | `<details>` 前三角旋转 90° |
| 无结果 | 居中提示＋「放宽筛选条件」引导，不显示空白 |
| 加载 | 无异步加载，不存在空白等待；数据一次性载入（1.86 MB） |
| 筛选生效 | 筛选条下方出现条件 chip，下拉框变主色描边 |
| 搜索待提交 | 输入框有内容但未提交时，列表不变；按回车或点「搜索」后整页重绘 |

所有核心操作都是**显性文字按钮**（清空筛选、上一事件、下一事件、回到顶部、放大、缩小、复位、返回列表），不依赖悬停或图标猜测。

## 7. 时间轴

- 横轴为**等距年代刻度**（前 620 — 1930），未做非线性压缩，避免视觉上夸大某些时段。
- 上方为朝代分区带，宽度按实际年代跨度；过窄的朝代（秦、新、三国、西晋、隋、五代）不标名，缩放后出现。
- 节点按类型着色，图例常驻；图例末句说明纵向位置仅用于避让重叠。
- **区间事件画成长条**（按起止年跨度），**推定年份画空心虚线圆点**，单年为实心圆点。
- 纵向位置仅用于避让重叠，以中线为轴上下交替展开，**不含数值含义**（图例中已注明）。
- 点击节点或列表中的「查看详情」→ 在当前页弹出**预览窗**（含完整史料），窗内再点「跳转至事件名录」才进入名录对应条目；点列表行本身只在轴上定位并高亮，不跳页。
- 缩放 1×/2×/4×/8×，超出容器时横向滚动；刻度密度随宽度自动调整（50/100/200/250/500 年）。
- 年代不详的事件单列在时间轴下方，不强行塞入轴内。

## 8. 历史地图

三段式布局，控制区不折叠、不藏菜单：

```
┌──────────────────────────────────────────────┐
│ 控制区  朝代｜年份｜事件类型｜定位精度｜重置      │
│        图层：地形晕渲 水系 湖泊 海岸线｜点位 密度 │
├───────────────────────────────┬──────────────┤
│ 地图主体（地形 + 矢量 + 点位）   │ 右侧详情      │
└───────────────────────────────┴──────────────┘
```

- **控制区**：朝代下拉、年份起止、事件类型、定位精度（只列实际存在的等级并带数量）、重置筛选；第二行是图层开关与「事件点位／密度分布」切换。
- **地图主体**：铺满剩余空间，支持拖拽平移、＋/－按钮缩放、Ctrl/⌘ + 滚轮缩放、复位；缩放范围 1×–6×（1× 即铺满，不再缩小），平移有边界夹取，不会露出空白；左下角图例、右下角比例尺、上缘经纬注记。
- **右侧详情**：未选中时显示引导语与「事件最多的地点」快捷列表；选中后显示地名、今地对照、定位精度、关联事件数、事件列表。点事件 → 先弹出预览窗，再由窗内按钮跳转名录。
- **聚合**：屏幕距离 12 px 内的点位合并为一个标记，事件数累加、地名并列；缩放后自动拆分。
- **联动**：朝代、类型、年份筛选与名录、时间轴共享；在地图选「唐」，切到名录仍是 39 条。

## 9. 地点索引

- **顶部只有一个搜索框**（与人物索引一致）：地名、今地、层级／分区、所属事件的朝代年代概述都可检索，回车或点「搜索」生效；不显示朝代／类型／地点／年份等下拉，也不与名录的筛选联动。
- **地点**：按河洛、关中、齐鲁、河北、河东、江淮、荆楚、江南、巴蜀、陇右、塞北、岭南、跨区域、部族、通语分组；每卡显示基名、层级、今地、事件数（定位精度见悬停提示与详情页）。点击 → 名录并带上地点条件。
- 计数行注明「共 N 处，关联 M 条事件」；搜索时给出「共 N 处（全部 246 处）」。
- 点地点卡 → 当前页弹出**地点预览窗**：上部为地名、今地、精度、关联事件数，下部为该地事件列表；点任一条可切到该事件的详情预览，窗内按钮可跳转名录（按此地点筛选）。

## 9b. 人物索引

- **人物**：236 位，按关联事件数排列，显示事件数、记载数与年代；点击展开该人物的事件表，可按「← 返回人物索引」退回。
- 人物索引与地点索引各自独立成页，互不混排；`无（志体不系人）`、`不详` 不入索引。
- 人物搜索框支持按姓名与所属事件检索，随名录的朝代／类型等条件联动。

## 9c. 预览窗（不离开当前页）

时间轴、历史地图、地点索引、人物索引里点事件，不再直接跳到事件名录，而是先弹出预览窗：

- **事件预览**：与名录右侧详情同一套内容（头部标签、基本信息、事件概述、全部相关史料），「查看整篇原文」照常可用；顶部按钮为「跳转至事件名录 →」。
- **地点预览**：显示地名、今地、定位精度，并列出该地关联事件；点其中一条即切换为该事件的预览。
- 关闭方式：右上「关闭」、点遮罩、Esc 三选一。
- 跳转后：事件预览 → 名录打开该条并展开详情；地点预览 → 名录按该地点筛选。
- 名录页自身仍是点击即选中（不走预览窗）。

## 10. 整篇原文阅读器

每条史料卡（事件详情与排除材料两处）页脚有「查看整篇原文」按钮。

- 点击后弹出阅读层，标题为「史书 · 篇名」，正文为该篇全文（繁体，据底本，未删节），按自然段排版。
- 命中处按 `sent_start/sent_end` 精确定位，黄底标出，并自动滚动到视野中央；顶部另有「定位到命中处」可再次回位。
- 原文按史书拆为 25 个文件，首次点开某部时才注入对应脚本（最大 1.9 MB），首屏不受影响；同一部内再点不重复加载。
- 关闭方式：右上「关闭」、点击遮罩、按 Esc。
- 若 `assets/texts/` 缺失，弹层提示「原文未随包提供」，史料卡中的命中段落不受影响。

## 11. 简体对照开关

页头右侧「简体对照」按钮控制 `body.sim-on`：

- 关闭（默认）：只显示繁体底本原文，最忠实。
- 开启：在原文下方追加机器转换的简体段落，带「仅供阅读，引用以繁体为准」标注。
- 选择记入 `localStorage`，刷新后保持。

## 12. 无障碍与细节

- 所有可点击元素为 `<button>` 或带 `cursor:pointer` 的容器，键盘 Tab 可达。
- 输入框带 `aria-label` 或占位说明；清除按钮带 `aria-label`。
- 长史料不会撑破布局：`text-align:justify` + 段落容器自适应，详情区独立滚动。
- 移动端断点 1080 / 820 / 520 px 三档。

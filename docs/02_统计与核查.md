## 6. 核查项与结果

| 核查项 | 方法 | 结果 |

| 事件计数 | `len(events)` 与 `meta.counts.events` | 260，一致 |

| 独立记载数 | `n_indep <= n_records` | 260/260 通过 |

| 序号连续 | `excluded[].seq` 与 `_eid` | 1–323 连续，无重号 |
| 高亮偏移 | `full[hs:he]` 是否等于底本 `[sent_start:sent_end]` | 720 条全部逐字相同，0 例外 |

| 坐标完整性 | 除 macro／unknown 外是否均有经纬度 | 通过 |

## 7. 与一库、二库的差额对账

```
事件：201 + 61 − 2（EV2017 重复、EV2049 降级）        = 260
记载：311 + 66 − 2（同上两条所辖）＋ 22（挂靠）        = 397
排除：210 + 113                                       = 323
地点：204（一库）＋ 42（二库新增与订正）              = 246
人物：164 + 72（二库新增，按单名拆分）                 = 236
```

地点差额「＋42」为净增：二库并入了 45 处新地名，同时按用户订正撤并了 3 处（洛阳金光门并入长安、淮安杨村桥并入淮安、汝州郏城／漳州龙溪／莱州即墨等简写为汝州／龙溪／即墨）。

## 8. 未作统计的口径

- 不统计「人相食发生次数」：一条记载可能对应多次发生，一次发生也可能见于多书。
- 不按现代省区统计：历史地名与现代政区不一一对应，地点索引只给今地参照。
- 不把排除材料计入事件率：两类材料性质不同，分母不可混用。
